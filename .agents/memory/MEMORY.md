- [EAS build git lock workaround](eas-build-git-lock.md) — prefix `GIT_OPTIONAL_LOCKS=0` to run `eas-cli build` for the yoann2 Expo app; plain `eas build` fails on `.git/index.lock`.
- [EAS Build fix — yoann2](eas-build-fix.md) — lockfile sync, minSdkVersion via plugin, account `stpyoann`/`yoann-20`; use `export EXPO_TOKEN` not inline.
- [Expo Android crash diagnosis](expo-android-crash-diagnosis.md) — splash-then-close = uncaught JS error in index.js/root render before React (guard sync native calls); instant-close = native init crash; Reanimated 4 requires New Arch.
- [react-native-android-widget color format](rn-android-widget-colors.md) — use 6-digit `#RRGGBB` hex only; 8-digit `#RRGGBBAA` = CSS format (alpha last), NOT Android `#AARRGGBB`.
- [react-native-android-widget style API constraints](rn-android-widget-styles.md) — FlexWidgetStyle: use `flexGap` not `gap`; no `flexWrap`, no percentage widths.
- [RNTP incompatible New Architecture](rntp-new-arch-crash.md) — react-native-track-player 4.1.2 incompatible New Architecture/Bridgeless (RN 0.81+) — l'import JS crashe au module load. Utiliser notifee FGS à la place.
- [notifee FGS shortService bug](notifee-fgs-shortservice.md) — notifee core AAR (202108261754) déclare ForegroundService avec foregroundServiceType="shortService"; Android 14+ tue ce type immédiatement sur One UI 7. Override via plugin Expo withNotifeeManifest.js : shortService → dataSync.
- [notifee registerForegroundService placement](notifee-fgs-placement.md) — appeler registerForegroundService dans tripSession.ts (niveau module), PAS dans _layout.tsx. Les widget task handlers tournent en contexte headless sans _layout.tsx.
- [Expo config plugin — expo/config-plugins](expo-config-plugin-import.md) — utiliser require('expo/config-plugins') pas require('@expo/config-plugins') dans les plugins du projet yoann2 (pas installé séparément, disponible via expo).
